# 来源、版本关系与二次创作边界

这份文档回答三个问题：**这片的原作是谁的、v2 改了什么、凭什么说它同源。**

---

## 1. 上游来源

| 项目 | 值 |
|---|---|
| 原作仓库 | [RoyceBella-commits/The-Pelican-Test](https://github.com/RoyceBella-commits/The-Pelican-Test) |
| 原作许可 | MIT |
| 原作首次提交 | 2026-10-20 |
| 原作发布渠道 | [B 站 · BV1pLnw6YEzq](https://www.bilibili.com/video/BV1pLnw6YEzq/)（播放 19.7 万） |
| 原作片长 | 137.00 s / 8220 帧 |

原作是一支全程序化短片：一只鹈鹕骑车穿过 20 个艺术时代，每一格的画法由各时代的美术特征决定。
片中不含任何手绘素材或录音 —— 画面由 p5.js + p5.brush 实时计算，音乐由 Web Audio 合成。

本仓库以原作为基础。**原作的程序化框架、美术实现与配乐引擎予以保留并署名**，
v2 改写的是叙事、文本与音乐主题（见下）。

## 2. v2 是什么

v2 把「穿过美术史」改造为一条**追逐线**：

> 风把一张画吹走了。鹈鹕骑上自行车去追。

每穿过一道画框，世界换一种画法；那张被追的画也随时代被重新画一遍，
直到最后落在鹈鹕手里 —— 而画上画的正是它自己。

| | 原作 `main` | v2 |
|---|---|---|
| 叙事 | 线性巡礼 | 追逐（有目标物、有落点） |
| 格数 | 20 | **24** |
| 片长 | 137.00 s | **161.00 s** |
| 主题旋律 | 原作 THEME | 重写：上行模进 + 画的高音回旋动机 + 追逐动机 |
| 片头 / 片尾文案 | 「人类自古以来就痴迷于画鹈鹕骑自行车」/「人类共提交了 20 份答卷」 | 全部替换 |
| 新增装置 | — | 被追的画（`src/main/paper.js`）、伸翅去够的追逐动作 |

### 新增的四个时代

不是又多画一个世纪，而是每一格提出一个**新的绘制问题**：

| # | 时代 | 这一格要解决的问题 |
|---|---|---|
| 21 | 伊斯兰几何 | 没有主体 —— 规则本身就是题材；鹈鹕成为纹样里被挖去的一块 |
| 22 | 拜占庭马赛克 | 图像由离散方块构成；金色靠不透明平涂而非水彩叠色 |
| 23 | 非洲面具 | 正面平面造型，而其余 23 格都是侧影 |
| 24 | 包豪斯构成 | 只用圆、矩形、三角等几何原语组装出鹈鹕 |

### 文本替换的范围

原作者的表达性文字在 v2 里**全部移除**，换成新的叙事文案：

- 片头：「人类自古以来就痴迷于画鹈鹕骑自行车。——早在自行车被发明之前」
  → 「风把一张画吹走了。——鹈鹕骑上自行车去追。」
- 片尾：「截至目前，人类共提交了 20 份答卷。鹈鹕本人对此尚未发表评论」
  → 「追了 24 个时代，那张画终于落下来。画上画的，正是它自己。」

各时代的美术简报（`briefs/`）属于原作的实现材料，保留原样。

## 3. 凭什么认定同源

v2 建立在原作代码之上，这一点有可复现的证据，不是声明。

### 配乐互相关

把原作代码渲染出的配乐与 B 站音轨做归一化互相关：

| | 时长 | peak | rms |
|---|---|---|---|
| 原作渲染 | 137.00 s | 0.889 | 0.1133 |
| B 站音轨 | 137.00 s | 0.880 | 0.1130 |

- 全长归一化互相关：**0.9995**
- 22 个 6 秒段逐段：全部 ≥ **0.9930**

差异只来自 B 站的上传转码。同源的音轨不可能是这个相关系数 ——
这同时证明了「本仓库就是那支视频的源码」。

### 规模与架构

| | 原作 |
|---|---|
| 场景代码 | 1,518,158 字节 |
| 美术简报 | 44 份 + `STYLE.md` 总纲 |
| 响度处理 | `audio/levels.json` 逐时代人工标定 |
| 音频架构 | `audio/` 六模块（dsp / engine / eras / instruments / score / tape） |
| p5.brush | 2.2.3 |

v2 沿用这套结构，只在 `src/scenes/` 增加四个文件、在 `audio/score.js` 重写主题、
在 `src/main/` 增加 `paper.js` 与追逐逻辑。
